## Wall bottom offset (plan-core `Wall.bottom_offset`, plan-3d `wall.rs` / `wall_kinds.rs`, `dialogs/wall.rs`)
`Wall.bottom_offset` (serde default 0, inches) is where the wall starts above the floor it is drawn on, like Chief's wall "Bottom" value: the wall spans `bottom_offset..bottom_offset + height`. plan-3d honors it for standard walls and every straight class of `wall_kinds` (the standard builder shifts its frame and re-measures the holes; `build_class` grounds the wall and shifts the base). Opening sill heights stay measured from the floor, so `hole_for` only cuts the part of an opening between the wall's bottom and top. The Wall Specification dialog has a General "Bottom Height" field (negative values are refused). Open: `flags.railing` walls in `plan-3d/lib.rs` ignore it; the 2D plan, room detection, elevations (`plan-elevation`), schedules and wall framing do not know it yet.

## 3D picking (open: needs view3d_panel.rs)
`view3d_panel.rs` exposes no pick hook and was not in this pass. The plan-side half is done: `editor::selection::object_for_mesh_id(&project, mesh.object_id) -> Option<(floor, ObjectRef)>` resolves a mesh's `object_id` (walls, openings, symbols, cabinets, stairs, roof records, foundation objects, framing, details, devices). The panel needs a click handler in `show`, after `let resp = vp.ui(ui, size);`:
```rust
if resp.clicked() {
    if let Some(pos) = resp.interact_pointer_pos() {
        // Ray through the clicked pixel (the camera's eye/forward/up and vertical fov).
        let aspect = rect.width() / rect.height().max(1.0);
        let (nx, ny) = ((pos.x - rect.min.x) / rect.width() * 2.0 - 1.0, 1.0 - (pos.y - rect.min.y) / rect.height() * 2.0);
        let cam = &vp.camera;
        let (fwd, up0) = (cam.forward(), [0.0, 1.0, 0.0]);
        let right = normalize(cross(fwd, up0));
        let up = cross(right, fwd);
        let half_h = (vertical_fov(cam.fov_deg, aspect).to_radians() * 0.5).tan();
        let dir = normalize(add3(fwd, add3(scale(right, nx * aspect * half_h), scale(up, ny * half_h))));
        // Nearest triangle of any mesh that has an object_id (Moller-Trumbore over st.scene.meshes).
        if let Some(id) = nearest_object_id(&st.scene, cam.eye(), dir) {
            if let Some((fl, obj)) = crate::editor::selection::object_for_mesh_id(&cx.project, id) {
                cx.floor = fl;
                cx.selection.set(obj);
            }
        }
    }
}
```
(`normalize/cross/add3/scale/nearest_object_id` are small local helpers; orthographic modes need `origin = eye + right * nx * half_width + up * ny * half_h` with `dir = fwd` instead.) `cx.selection` is what Select Objects and the Edit toolbar read, so the plan highlights the object when the user returns to it.
