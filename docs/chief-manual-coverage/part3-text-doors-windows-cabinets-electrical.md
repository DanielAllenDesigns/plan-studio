# Chief X18 Reference Manual audit, part 3: Text, Doors, Windows, Cabinets, Electrical, Schedules, Foundations, Fireplaces (manual pages 521 to 761)

Written 2026-10-08 on branch wip/round-14-partial (HEAD 129890a, with the Round 15 builders still editing the tree). Daniel's purpose: find every Chief feature that is not installed yet. This is a docs-only audit: no Rust was edited and no cargo was run.

**Method.** Every page of the Reference Manual from 521 to 761 was read from the extracted text at `~/plan-studio-dev/chief-docs/` (read only; nothing of it is copied here, every row below is in our own words and only dialog, tool and field names are Chief's). The range holds eight chapters: Text, Callouts, and Markers (pp. 521-570), Doors (571-602), Windows (603-642), Cabinets (643-690), Electrical (691-707), Schedules and Object Labels (708-736), Foundations (737-755) and Fireplaces with Chimneys (756-761). For each feature the status was taken from `docs/chief-feature-coverage.md` (the Round 14 audit), then `docs/parity/*.md` and `docs/parity-status.md`, then the code in `crates/` (grep and reading of the tools, dialogs and model slots), then `DECISIONS.md`, and the Round 15 briefs in `~/plan-studio-dev/briefs` were checked for work in flight.

**Status words.** Works; Partial (present with a stated gap); Missing; Differs (by design or by decision); Out-of-scope (Ruby, cloud, licensing, 3D Warehouse, VR or vendor services); In progress (Round 15) when a brief covers it and the code is not finished. Evidence "NO SPEC -> ID" means no parity id covered the feature before this audit; the new id is appended to the matching `docs/parity/*.md` file under "Manual audit additions (part 3)" and to `docs/parity-status.md`.

**Page numbers** are the printed page numbers of the manual (the numbers in its table of contents).

Contents: 1 Text, Callouts, and Markers; 2 Doors; 3 Windows; 4 Cabinets; 5 Electrical; 6 Schedules and Object Labels; 7 Foundations; 8 Fireplaces and Chimneys; then "Dialog panels" (the panel-by-panel comparison), "Gaps to build" (ranked), "Contradictions with DECISIONS.md" and "Counts".
