# Differences from Chief found by the manual triage (2026-10-10)

Each row is a fix candidate for the next waves; verify against the current code first (some may already be built).

|---|---|---|---|
| 43 | 575, 589, 415, 622, 623 | Jamb drawn in plan (p. 575), Swings Both Directions (p. 589) and Exterior Sill on the Lintel tab (p. 623) match.
