## Wall bottom offset (plan-core `Wall.bottom_offset`, plan-3d `wall.rs` / `wall_kinds.rs`, `dialogs/wall.rs`)
`Wall.bottom_offset` (serde default 0, inches) is where the wall starts above the floor it is drawn on, like Chief's wall "Bottom" value: the wall spans `bottom_offset..bottom_offset + height`. plan-3d honors it for standard walls and every straight class of `wall_kinds` (the standard builder shifts its frame and re-measures the holes; `build_class` grounds the wall and shifts the base). Opening sill heights stay measured from the floor, so `hole_for` only cuts the part of an opening between the wall's bottom and top. The Wall Specification dialog has a General "Bottom Height" field (negative values are refused). Open: `flags.railing` walls in `plan-3d/lib.rs` ignore it; the 2D plan, room detection, elevations (`plan-elevation`), schedules and wall framing do not know it yet.
